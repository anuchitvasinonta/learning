# Chinese

Learning Mandarin, focused on speaking and listening — not character
reading/writing.

## Current goal

4-week trip-prep sprint before a trip to **Kunming and Lijiang** (Yunnan).
Target: handle common practical situations while traveling —

- basic greetings & courtesy
- ordering food (restaurants + street food)
- shopping & bargaining, numbers/money
- directions, transport, hotel check-in
- asking for help / "I don't understand" / emergencies

No character reading/writing goal. Pinyin + listening/speaking only, and
practice should use **real native-speaker audio** (not TTS) for
familiarization — see `course-plan.md` for the method and resource list.

Progress logged in `log.md`.
